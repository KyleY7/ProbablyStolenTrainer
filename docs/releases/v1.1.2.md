# v1.1.2 — Connection fix and item library / 连接修复与物品库

## 简体中文

**仅供学习，欢迎大家反馈。** 问题与建议可提交到 [GitHub Issues](https://github.com/KyleY7/probably-stolen-trainer/issues)。

适配 **Probably Stolen Demo，Steam 构建 25382790 / Windows x64**，需要 .NET Framework 4.8。用户已确认本版可正常使用。

- 修复进入店铺后仍无法连接的问题：从已加载的声望对象识别类型，避免误读游戏尚未解析的类型标记。
- 提供金钱、天数、租金倒计时、单个或全部势力声望修改。
- 支持选择游戏进程和中英文即时切换，自动识别安装目录。
- 支持游戏原生鉴定物真实价值提示。
- 新增物品库开关：按修改器显示的实际快捷键打开游戏物品库，将物品拖入店铺后仓空位。
- 包含存档备份、最近一次数值修改撤销、操作日志与连接诊断。

**下载与使用：** 下载 `ProbablyStolenTrainer-v1.1.2-win-x64.zip`，解压后运行 `ProbablyStolenTrainer.exe`；也可下载单独 EXE。进入店铺后选择游戏进程，修改前先备份存档。程序应在运行游戏的同一套 Windows 中使用。

**后仓添加物品：** 勾选“开启物品添加菜单”，切回游戏按显示的快捷键，从物品库拖放商品到后仓。先按同一快捷键关闭物品库，再取消开关或退出修改器。新增物品由游戏正常保存，不属于数值撤销范围。

**验证：** 60 项自动测试通过，原连接故障已复现并修复，中英文界面已检查。用户反馈本版可用；尚未逐项完成全部功能和保存回读的独立实机验证。仅支持上述试玩版构建。

## English

**Provided for learning purposes only. Feedback is welcome.** Report issues and suggestions through [GitHub Issues](https://github.com/KyleY7/probably-stolen-trainer/issues).

Supports **Probably Stolen Demo, Steam build 25382790 / Windows x64**, with .NET Framework 4.8. The user has confirmed this build works in the game.

- Fix connection failure after entering the shop by validating loaded reputation objects instead of reading an unresolved type token as a pointer.
- Edit money, day count, rent countdown and one or all factions' reputation.
- Select the game process, detect its directory automatically and switch between Chinese and English instantly.
- Reveal the game's native true-value tooltip for supported appraisal items.
- Open the native item library with the actual shortcut displayed by the trainer and drag merchandise into free back-room inventory space.
- Includes save backups, undo of the latest numeric edit, change logs and connection diagnostics.

**Download and use:** extract `ProbablyStolenTrainer-v1.1.2-win-x64.zip` and run `ProbablyStolenTrainer.exe`, or download the standalone EXE. Enter the shop, select the game process and back up saves before editing. Run the trainer in the same Windows installation as the game.

**Adding stock:** enable the item library, return to the game and press the displayed shortcut. Drag items into the back room. Close the library with the same shortcut before disabling the toggle or exiting the trainer. Added items follow normal game saving and are outside numeric Undo.

**Validation:** all 60 automated checks pass; the original connection failure was reproduced and fixed, and both UI languages were checked. The user reports this build works; independent live-game validation of every feature and save/reload behavior is not complete. Only the specified Demo build is supported.
