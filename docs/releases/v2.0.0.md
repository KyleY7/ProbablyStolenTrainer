# v2.0.0 — Terminal-inspired UI / 终端风格新版界面

## 简体中文

**仅供学习，欢迎大家反馈。** 问题与建议可提交到 [GitHub Issues](https://github.com/KyleY7/probably-stolen-trainer/issues)。

2.0 采用接近 Claude Code 的简洁终端风格：暖纸色背景、陶土橙强调色、等宽标题、细线分组和操作记录区。主窗口与进程选择窗口均重新设计。

- 将数值修改、势力声望、游戏辅助和会话操作分组，当前值与目标值并排显示。
- 改善禁用按钮、开关和键盘焦点的可读性，连接按钮突出显示。
- 主窗口可调整大小，启动时适应当前屏幕工作区；缩小时可滚动访问下方控件和日志。
- 保留金钱、天数、租金倒计时、声望、鉴定价值、后仓物品库、备份、撤销及中英文切换。
- 沿用 v1.1.2 已确认可用的游戏连接和数值处理逻辑，适配范围仍为 **Probably Stolen Demo / Steam 构建 25382790**。

**下载：** 解压 `ProbablyStolenTrainer-v2.0.0-win-x64.zip` 后运行 `ProbablyStolenTrainer.exe`；也可下载单独 EXE。需要 Windows 10/11 x64 和 .NET Framework 4.8。先退出旧修改器，再启动新版并选择游戏进程。

**后仓添加物品：** 开启物品库后，切回游戏按修改器显示的实际快捷键，将商品拖到后仓空位。先用同一快捷键关闭物品库，再取消开关或退出。新增物品不属于数值撤销范围。

**验证：** 61 项自动测试通过，包括缩小窗口后的实际滚动，以及中英文切换保留连接、输入、开关和撤销状态。已检查主窗口与进程选择器的中英文截图和未连接状态。v1.1.2 的游戏使用已获用户确认；2.0 的新版界面尚未逐项完成真实游戏会话验证，高 DPI 环境也未穷举测试。

## English

**Provided for learning purposes only. Feedback is welcome.** Report issues and suggestions through [GitHub Issues](https://github.com/KyleY7/probably-stolen-trainer/issues).

Version 2.0 introduces a clean terminal-inspired interface with a Claude Code-like feel: warm paper backgrounds, terracotta accents, monospace headings, fine borders and an activity area. Both the main window and process picker are redesigned.

- Group numeric edits, reputation, game tools and session actions, with current and target values side by side.
- Improve disabled buttons, toggles and keyboard-focus visibility, with a prominent connection button.
- Resize the main window; it fits the current screen's working area on launch and scrolls to keep lower controls and logs reachable in smaller windows.
- Retain money, day, rent countdown, reputation, appraisal values, the back-room item library, backups, undo and Chinese/English switching.
- Use the game-connection and editing logic from the working v1.1.2 build. Compatibility remains **Probably Stolen Demo / Steam build 25382790**.

**Download:** extract `ProbablyStolenTrainer-v2.0.0-win-x64.zip` and run `ProbablyStolenTrainer.exe`, or use the standalone EXE. Requires Windows 10/11 x64 and .NET Framework 4.8. Close the previous trainer, launch this build and select the game process again.

**Adding stock:** enable the library, return to the game and press the displayed shortcut. Drag merchandise into free back-room space. Close the library with the same shortcut before disabling the toggle or exiting. Added items are outside numeric Undo.

**Validation:** all 61 automated checks pass, including scrolling in a smaller window and language switching that preserves connection, inputs, toggles and undo. Chinese/English main-window and process-picker previews and the disconnected state were inspected. The user confirmed v1.1.2 worked in the game; version 2.0 has not received complete independent live-game or exhaustive high-DPI validation.
